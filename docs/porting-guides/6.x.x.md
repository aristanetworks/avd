# Porting Guide for Ansible AVD 6.x.x

Major releases of AVD can contain breaking changes. This porting guide addresses how to update your inventory
and playbooks to be compatible with new default behaviors and changed data models when upgrading from AVD 5.x versions.

Users of `eos_designs` need to consider the changes in `eos_cli_config_gen` when using structured configuration.

## Changes to role arista.avd.eos_designs

### Adding pool of valid values to interface speed

#### `default_interfaces[].mlag_interfaces_speed` and `default_interfaces[].uplink_interface_speed` requires value assignment from valid values pool

In AVD 5.0.0, any string value could be assigned to default_interfaces.mlag_interfaces_speed and default_interfaces.uplink_interface_speed.

As of AVD 6.0.0, default_interfaces.mlag_interfaces_speed and default_interfaces.uplink_interface_speed must be assigned a value from the predefined pool of valid values.

#### `adapter_config.speed` requires value assignment from valid values pool

In AVD 5.0.0, any string value could be assigned to adapter_config.speed.

As of AVD 6.0.0, adapter_config.speed must be assigned a value from the predefined pool of valid values.

#### `network_services[].vrfs[].l3_port_channels[].member_interfaces[].speed` requires value assignment from valid values pool

In AVD 5.0.0, any string value could be assigned to network_services[].vrfs[].l3_port_channels[].member_interfaces[].speed.

As of AVD 6.0.0, network_services[].vrfs[].l3_port_channels[].member_interfaces[].speed must be assigned a value from the predefined pool of valid values.

#### `node_type.uplink_interface_speed`, `node_type.uplink_switch_interface_speed`, `node_type.mlag_interfaces_speed`, `node_type_l3_interfaces[].speed` and `node_type_l3_port_channels[].member_interfaces[].speed` requires value assignment from valid values pool

In AVD 5.0.0, any string value could be assigned to node_type.uplink_interface_speed, node_type.uplink_switch_interface_speed, node_type.mlag_interfaces_speed, node_type_l3_interfaces[].speed and node_type_l3_port_channels[].member_interfaces[].speed.

As of AVD 6.0.0, node_type.uplink_interface_speed, node_type.uplink_switch_interface_speed, node_type.mlag_interfaces_speed, node_type_l3_interfaces[].speed and node_type_l3_port_channels[].member_interfaces[].speed must be assigned a value from the predefined pool of valid values.

#### `p2p_links[].speed` requires value assignment from valid values pool

In AVD 5.0.0, any string value could be assigned to p2p_links[].speed.

As of AVD 6.0.0, p2p_links[].speed must be assigned a value from the predefined pool of valid values.

## Changes to role `arista.avd.eos_cli_config_gen`

### `ethernet_interfaces[].speed` and `management_interfaces[].speed` requires value assignment from valid values pool

In AVD 5.0.0 , any string value could be assigned to ethernet_interfaces[].speed and management_interfaces[].speed items.

As of AVD 6.0.0, ethernet_interfaces[].speed and management_interfaces[].speed must be assigned a value from the predefined pool of valid values.
