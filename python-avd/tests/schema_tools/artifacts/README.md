The schema files in this directory are frozen copies used by the documentation-generation tests.
They keep the expected documentation stable as the production schemas evolve.
The current generated models are exercised by the molecule-scenario tests under `tests/pyavd/molecule_scenarios`.

The files in the ./output folder are temporary files generated by the tests.
