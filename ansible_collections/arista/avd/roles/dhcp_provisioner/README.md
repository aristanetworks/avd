# dhcp_provisioner

!!! danger "Role Removed"
    This role has been removed in AVD 6.0.0. The role is not compatible with modern DHCP servers and should not be used for production.

## Migration

The `arista.avd.dhcp_provisioner` role is released as open source, so it can be copied and reused according to the license and copyright.

Please refer to the [porting guide](https://avd.arista.com/6.x/docs/porting-guides/6.x.x.html) for more information.
