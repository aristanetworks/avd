## C

### circuit_id_format

**Type**: String  
**Path**: `ip_dhcp_snooping.information_option.circuit_id_format`  
**Valid Values**: `%h:%p`, `%p:%v`  

Required if `circuit_id_type` is set.
- "%h:%p" Hostname and interface name
- "%p:%v" Interface name and VLAN ID
