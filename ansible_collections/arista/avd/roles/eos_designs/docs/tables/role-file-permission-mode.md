=== "Table"

    | Variable | Type | Required | Default | Value Restrictions | Description |
    | -------- | ---- | -------- | ------- | ------------------ | ----------- |
    | [<samp>avd_dir_mode</samp>](## "avd_dir_mode") | String |  |  |  | Directory permissions mode (octal string) to be applied to all directories created by the role.<br>Default is "0o775".<br> |
    | [<samp>avd_file_mode</samp>](## "avd_file_mode") | String |  |  |  | File permissions mode (octal string) to be applied to all files generated by the role.<br>Default is "0o664".<br> |

=== "YAML"

    ```yaml
    # Directory permissions mode (octal string) to be applied to all directories created by the role.
    # Default is "0o775".
    avd_dir_mode: <str>

    # File permissions mode (octal string) to be applied to all files generated by the role.
    # Default is "0o664".
    avd_file_mode: <str>
    ```
